# Installing and Updating

## Installing

1. Ask for the installer by email at [info@lvlmotion.com](mailto:info@lvlmotion.com).
2. Run `LEVEL_Collector-<version>.exe`.
3. Open **LEVEL Collector** from the Start menu (under **LvlMotion**) or the
   desktop shortcut.

After installing, open **Settings** once: see [Settings](windows-settings) for
the Python setup (plotting, Polar, Sony and Vicon need it) and the sync table.

## Updating

- New versions come as a new installer (by email). Run it: it replaces the old
  version and keeps your settings, recordings and Python environment.
- The window title and the first line of the **Logs** tab show the version.
- If Windows refuses to install (the new version is not newer than the one
  installed), uninstall the old one first (Settings > Apps). Your settings and
  recordings are kept.

## Getting help

- On the **Logs** tab, **Copy all** puts the whole log on the clipboard so you
  can paste it into an email to [info@lvlmotion.com](mailto:info@lvlmotion.com).
  The full log of each run is also saved under `LEVEL_Collector\logs` in your user
  folder.
