# LEVEL Collector for Windows

The desktop recorder is the computer app (separate from the phone app) that
records the IMU sensors over the USB dongle and coordinates the optional sync
sources - Vicon, Sony/Theia cameras, and Polar. It runs on a lab or clinic PC.

Start with **First install**, then **Running a recording**. For the fixed offsets
and calibration between systems, see **Syncing with other systems**.
